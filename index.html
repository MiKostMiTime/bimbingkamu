Layanan AI Terdaftar

    Panduan Setup

    ☁️ Cloud

    Paling mudah

    Cloud = layanan AI yang berjalan di internet. Tinggal pilih, tempel kunci API, langsung belajar. Butuh koneksi internet, dan sebagian model berbayar — pilih model berlabel Gratis bila belum punya saldo.

    1. Pilih OpenRouter, Gemini AI Studio, atau OpenAI di daftar “Layanan AI Aktif”.
    2. Klik Sunting pada layanan itu → tempel Kunci API → Simpan perubahan.
    3. Pilih model, lalu mulai belajar!

    Kunci API itu apa? Kode rahasia dari website penyedia (biasanya di menu API keys akunmu). Anggap seperti password: jangan dibagikan, dan jangan tempel di tempat lain.

    📱 Mobile

    LM Studio di HP

    HP tidak diizinkan memanggil alamat http:// ke komputer di jaringan rumah. Jadi LM Studio diakses lewat alamat HTTPS dari komputer yang menjalankannya. Jalur ini disebut tunnel (terowongan).

    1. Di komputer: nyalakan server LM Studio (port 1234), centang Enable CORS (artinya: izinkan browser mengakses server ini).
    2. Di komputer yang sama, buka Terminal dan jalankan ngrok http 1234.
    3. Salin alamat https://....ngrok-free.app yang muncul.
    4. Di HP: buka BimbingKamu → Pengaturan → Tambah layanan, lalu tempel alamat itu di kolom Alamat API.
    5. Bila LM Studio memakai Require Authentication, buat token di Developer → Server Settings → Manage Tokens dan tempel di kolom Kunci API.
    6. Pilih model, lalu mulai belajar.

    Tanpa ngrok: cloudflared tunnel --url http://localhost:1234. Tunnel dijalankan di komputer, bukan di HP. Bila tidak bisa membuka Terminal, pakai opsi Cloud di HP.

    🖥️ LM Studio di komputer

    Desktop

    LM Studio berjalan di komputermu: gratis dan tanpa internet. Nyalakan servernya, izinkan browser mengaksesnya, lalu sambungkan lewat alamat API. Bila browser tetap memblokir alamat http://, pakai tunnel HTTPS seperti pada kartu Mobile di atas.

    1. Di LM Studio, buka Developer → Server Settings: nyalakan server (port 1234), centang Enable CORS, dan aktifkan Serve on Local Network bila diakses dari perangkat lain.
    2. Bila Require Authentication aktif, klik Manage Tokens → Create Token, salin tokennya (hanya tampil sekali).
    3. Di BimbingKamu, buka Pengaturan → Tambah layanan, isi Alamat API dengan http://localhost:1234. Tempel token di kolom Kunci API bila diperlukan, lalu klik Tambah layanan.
    4. Pilih model, lalu mulai belajar.

    Alamat dari perangkat lain: pakai http://10.xx.xxx.xxx:1234 (alamat komputer yang menjalankan LM Studio) dari laptop di Wi-Fi yang sama. Untuk HP atau akses dari luar jaringan, gunakan alamat HTTPS dari tunnel.
