# TanyaBukan PWA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengubah TanyaBukan menjadi Progressive Web App yang installable + offline-ready, dengan jaminan memori/setting/materi tidak hilang saat update/reinstall.

**Architecture:** Service Worker (ESM worker) meng-cache app shell & aset lokal; `pwa-cache.js` menyimpan logika cache yang murni & teruji; `pwa.js` mendaftarkan SW + mendeteksi update; `manifest.json` + ikon membuat app installable; `memory.js` diberi *version guard* agar skema storage tahan update. Semua same-origin (lokal), zero-CDN, konsisten dengan CSP `default-src 'self'`.

**Tech Stack:** Vanilla ES modules, Service Worker (module), Web App Manifest, localStorage. Uji: `node:test` + `node --test` (gaya sama dengan `tests/*.test.mjs`). Ikon: SVG → PNG via `rsvg-convert`, verifikasi dimensi via `sips`.

**Spec:** `docs/superpowers/specs/2026-11-05-pwa-design.md` (rencana ini arguing from spec — baca keduanya).

## Global Constraints
- **CSP tetap `default-src 'self'`** di `index.html`; manifest/SW/ikon harus same-origin → **jangan** menambah sumber eksternal ke CSP.
- **Tema warna:** `theme_color = #4F46E5` (`--color-accent`), `background_color = #FAFAFA` (`--color-bg`).
- **Nama app:** `TanyaBukan` (short_name `TanyaBukan`); copy Bahasa Indonesia.
- **localStorage key prefix:** `tanyabukan.*` (lihat `js/config.js`) — memori/setting/materi harus tetap di sini & selamat dari cache SW.
- **Display:** `standalone` (rasa app native).
- **Zero dependency baru** (tanpa workbox/PWA plugin) — SW ditulis manual.
- **Uji:** setiap task logika dijalankan `node --test`; seluruh suite dijalan di akhir (`node --test tests/`).

  ```javascript
  // TanyaBukan — PWA CACHE LOGIC (murni, teruji di Node; dipakai sw.js sebagai ESM worker).
  export const CACHE_VERSION = 'tanyabukan-shell-v1';
  export const OLD_CACHE_PREFIX = 'tanyabukan-shell-';

  export const PRECACHE_ASSETS = [
    './index.html',
    './css/variables.css',
    './css/main.css',
    './css/components.css',
    './js/app.js',
    './js/pwa.js',
    './manifest.json',
    './icons/icon-192.png',
    './icons/icon-512.png',
    './icons/maskable-1024.png',
  ];

  // Apakah URL aset milik app (same-origin / path relatif)?
  export function isOwnAsset(url, origin) {
    const u = typeof url === 'string' ? url : (url && url.href) || '';
    if (!u) return false;
    try {
      const base = new URL(origin);
      return new URL(u, origin).origin === base.origin;
    } catch {
      return true; // origin invalid → anggap path relatif (same-origin)
    }
  }

  export function selectStrategy(url, origin) {
    const u = typeof url === 'string' ? url : (url && url.href) || '';
    if (/\/sw\.js(\?|#|$)/.test(u)) return 'network-only'; // SW sendiri → selalu network
    if (isOwnAsset(u, origin)) return 'cache-first';        // aset lokal → offline-ready
    return 'network-first';                                 // API endpoint provider → network
  }
  ```

## Task 5: sw.js (Service Worker glue)

**Files:**
- Create: `js/sw.js`
- Test: verifikasi syntax + manual (SW browser-only).

**Interfaces:**
- Consumes: `CACHE_VERSION`, `PRECACHE_ASSETS`, `selectStrategy` dari `./js/pwa-cache.js`.
- Produces: SW dengan `install` (precache shell), `activate` (hapus cache versi lama berprefiks `OLD_CACHE_PREFIX`), `fetch` (strategy + offline fallback `index.html`).

- [ ] **Step 1: Write `js/sw.js`**
  ```javascript
  // TanyaBukan — SERVICE WORKER (ESM)
  import { CACHE_VERSION, OLD_CACHE_PREFIX, PRECACHE_ASSETS, selectStrategy } from './js/pwa-cache.js';

  const ORIGIN = self.location.origin;

  async function precache(list) {
    const cache = await caches.open(CACHE_VERSION);
    await cache.addAll(list);
  }

  addEventListener('install', (event) => {
    event.waitUntil(precache(PRECACHE_ASSETS));
  });

  addEventListener('activate', (event) => {
    event.waitUntil((async () => {
      const names = await caches.keys();
      await Promise.all(names
        .filter((n) => n.startsWith(OLD_CACHE_PREFIX) && n !== CACHE_VERSION)
        .map((n) => caches.delete(n)));
      await self.clients.claim();
    })());
  });

  addEventListener('fetch', (event) => {
    const req = event.request;
    if (req.method !== 'GET') return;
    const strategy = selectStrategy(req.url, ORIGIN);
    if (strategy === 'network-only') return; // SW sendiri: biarkan network default

    event.respondWith(handleFetch(req, strategy));
  });

  async function handleFetch(req, strategy) {
    if (strategy === 'cache-first') {
      const cache = await caches.open(CACHE_VERSION);
      const cached = await cache.match(req);
      if (cached) {
        // background refresh: simpan versi terbaru tanpa memblokir respons ke pengguna
        fetch(req).then((res) => {
          if (res && res.status !== 0) cache.put(req, res.clone());
        }).catch(() => {});
        return cached;
      }
      try {
        const fetched = await fetch(req);
        // bila gagal total (offline), fallback ke app shell
        if (!fetched || fetched.type === 'error') {
          const idx = await cache.match('./index.html');
          return idx || Response.error();
        }
        return fetched;
      } catch {
        const idx = await cache.match('./index.html');
        return idx || Response.error();
      }
    }
    // network-first (API endpoint provider)
    try {
      const resp = await fetch(req);
      return resp;
    } catch {
      const idx = await caches.open(CACHE_VERSION).then((c) => c.match('./index.html'));
      return idx || Response.error();
    }
  }
  ```

  ```javascript
  // TanyaBukan — PWA CLIENT
  export function shouldPromptUpdate(swState) {
    // swState: { installing?, installed?, waiting?, activating? } (boolean-ish)
    return !!(swState && swState.waiting);
  }

  let installListenerReady = false;

  export async function registerServiceWorker() {
    if (!('serviceWorker' in navigator)) return;
    try {
      const reg = await navigator.serviceWorker.register('./sw.js', { type: 'module' });
      // Deteksi update: saat SW baru terpasang & controller lama masih aktif → 'waiting'.
      reg.addEventListener('updatefound', () => {
        const installing = reg.installing;
        if (!installing) return;
        installing.addEventListener('statechange', () => {
          if (installing.state === 'installed' && navigator.serviceWorker.controller) {
            // Versi baru siap; controller akan switch saat reload → tampilkan prompt.
            showInstallPrompt();
          }
        });
      });
    } catch (err) {
      console.warn('[PWA] register Service Worker gagal:', err);
    }
  }

  let deferredPrompt = null;
  function showInstallPrompt() {
    if (!('showPrompt' in (deferredPrompt || {}))) return;
    const btn = document.getElementById('installBtn');
    if (btn) btn.click();
  }

  // Optional: tangkap beforeinstallprompt untuk tombol Install eksplisit.
  if (typeof window !== 'undefined') {
    window.addEventListener('beforeinstallprompt', (e) => {
      e.preventDefault();
      deferredPrompt = e;
    });
    registerServiceWorker();
  }
  ```
